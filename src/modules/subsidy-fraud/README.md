# Subsidy Fraud Prototype Module (체크리스트 25)

공공자료 기반 **보조금 부정수급 의심 후보**를 탐지하기 위한 프로토타입 모듈이다. 본 모듈은 부정수급 여부를 확정하지 않으며, 신고 채널·환수·처분·포상 여부는 공식 기준과 기관 판단에 따라 달라진다.

## 구성 파일

- `config.ts` — 모듈 메타데이터 / 안전 원칙
- `index.ts` — `ModuleDefinition` 등록 진입점 (status: `prototype`)
- `sources.json` — 공식 공개자료 소스 등록 + 금지 소스 정책
- `agency_config.json` — 신고처 후보 안내 (국민권익위/국민신문고/청렴포털/관리기관/지자체 감사)
- `risk_signals.json` — 9개 리스크 신호 정의 (반복 수급/동일 주소/유사 사업명/결과물 부족/금액 대비 산출물/특수관계/집행 패턴/공시 누락/콘텐츠 중복)
- `scoring_rules.ts` — 7개 점수 컴포넌트 (총 100)
- `report-template.md` — 신고서 초안 템플릿
- `sample-data.json` — 시범 지자체 1곳(충청남도 당진시) 합성 sample 데이터
- `collector.ts` — sample 기반 매칭/점수 분석기

## 시범 지자체

충청남도 당진시 (sample). 공공데이터포털에 당진시 지방보조금 데이터 예시가 공개되어 있음을 참고. `sample-data.json` 의 단체명/주소/대표자/금액은 모두 가상이다.

## 주의

- 부정수급 / 횡령 / 사기 / 범죄자 — 모두 단정 금지
- 개인정보 (주민번호 / 계좌 / 연락처 / 거주 주소) 수집 금지
- 비공개 보조금 자료 / 로그인 우회 / 무단 대량 크롤링 금지
- 공공데이터포털 인증키 커밋 금지
- 자동 신고 제출 / 자동 민원 제출 / 공식기관 자동 로그인 금지
- 포상금 수령 보장 없음
