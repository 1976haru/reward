## 5. 신고처 후보

- 국민권익위원회 / 국민신문고 (https://www.epeople.go.kr/)

- 관할 지자체 감사부서

구체적 신고 채널·환수·처분·보상 여부는 공식 기준과 처리 결과에 따라 달라질 수 있으므로 각 기관 공식 페이지를 직접 확인하세요.

## 6. 사람 검토 체크리스트

- [ ] 원본 공고/공시 URL이 공개 페이지인지 확인
- [ ] 단체명/대표/주소가 공식 등기·사업자 정보와 일치하는지 확인
- [ ] 결과보고서·집행증빙·정산자료가 비공개에 있을 가능성 확인
- [ ] 동일 주소·대표·용역업체 정황이 공식자료에서 재확인되는지 점검
- [ ] 사업 성격에 따른 집행 패턴 비교
- [ ] 민감정보(주민번호·계좌번호·연락처) 포함되지 않도록 점검
- [ ] 신고 채널 공식 안내 확인
- [ ] 포상금/보상 지급을 단정·약속하는 표현이 없는지 확인
- [ ] 최종 제출 문구를 사람이 직접 검토

## 7. 중립 검토 요청 문구

공개자료 기준으로 일부 반복 수급, 동일 주소, 결과물 부족 등 검토가 필요한 정황이 있어 관계기관의 확인을 요청드립니다.

본 문서는 부정수급을 단정하는 것이 아니라, 공개자료에 기반한 검토 요청 초안입니다.

## 8. 피해야 할 표현

- 부정수급 확정 / 횡령 확정 / 사기 단정
- 범죄자 / 사기꾼 단정 표현
- 무조건 처벌 요구
- 포상금/보상 지급 요구·지급 단정
- 특정 단체·개인·사업자를 부정수급자로 단정하는 표현
- 개인정보(주민번호·계좌·연락처·주소 등)
