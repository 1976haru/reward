> 본 문서는 **담합 여부를 확정하지 않습니다.** 공개 입찰 데이터 기반 검토 후보일 뿐이며, 조사·과징금·신고포상금 여부는 공정거래위원회 공식 기준과 처리 결과에 따라 달라집니다.

## 5. 추가 확인 필요자료

- 원본 입찰공고 (나라장터)

## 7. 사람 검토 체크리스트

- [ ] 원본 입찰공고/낙찰정보 URL이 공개 영역인지 확인
- [ ] 업체명 정규화가 단순 텍스트 비교 수준임을 인지하고 사업자 정보 공식 확인
- [ ] 동일 업체군이 정상 업종 경쟁의 결과일 가능성 검토
- [ ] 낙찰률 군집이 예정가격 산정/낙찰하한율 등 제도적 요인일 가능성 검토
- [ ] 들러리 후보 패턴은 단정이 아니라 의심 후보임을 명시
- [ ] 민감정보(연락처/계좌/내부자료) 포함되지 않도록 점검
- [ ] 신고 채널 공식 안내 확인
- [ ] 포상금 지급을 단정·약속하는 표현이 없는지 확인
- [ ] 최종 제출 문구를 사람이 직접 검토

## 8. 중립 검토 요청 문구

공개 입찰 데이터에서 동일 업체군 반복 참여, 순환 낙찰, 좁은 투찰 간격 등 검토가 필요한 패턴이 확인되어 관계기관의 확인을 요청드립니다.

본 문서는 담합을 단정하는 것이 아니라, 공개자료 기반의 패턴 분석 결과를 바탕으로 한 검토 요청 초안입니다.
