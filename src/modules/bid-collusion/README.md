# Bid Collusion Prototype Module (체크리스트 26)

정형 공개 입찰 데이터(나라장터 등)에서 **입찰담합 의심 패턴**을 탐지하기 위한 프로토타입 모듈이다. 본 모듈은 담합 여부를 확정하지 않으며, 실제 판단은 공정거래위원회·수사기관·법원 등 관계기관의 조사와 사람 검토가 필요하다.

## 구성 파일

- `config.ts` — 모듈 메타데이터 / 안전 원칙
- `index.ts` — `ModuleDefinition` 등록 진입점 (status: `prototype`)
- `sources.json` — 공식 공개자료 + 금지 소스 정책
- `agency_config.json` — 신고처 후보 (공정위 / 발주기관 감사 / 국민신문고)
- `risk_signals.json` — 9개 리스크 신호
- `scoring_rules.ts` — 8개 점수 컴포넌트 (총 100)
- `report-template.md` — 위험 업체군 검토 요청서 초안
- `sample-bids.json` — 합성 입찰 데이터셋 (30+ 입찰)
- `analyzer.ts` — 정규화 / 집계 / 패턴 탐지 / 그룹 스코어링

## 주의

- 담합 / 들러리 / 불법 업체 — 모두 단정 금지
- 특정 업체/개인/발주기관을 담합 주체로 단정 금지
- 비공개 입찰자료 / 로그인 우회 / 무단 대량 크롤링 / 인증키 커밋 금지
- 자동 신고 / 자동 민원 / 공식기관 자동 로그인 금지
- 포상금 수령 보장 없음 (공정거래위원회 공식 기준 확인 필요)
