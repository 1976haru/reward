# Agency Research

본 문서는 1차 MVP("건강기능식품 온라인 허위·과대광고 탐지") 모듈이 사용할 신고처와 공식 근거를 정리한다.
구체 데이터는 [`src/modules/false-ad/agency_config.json`](../src/modules/false-ad/agency_config.json)에 동기화되어 있다.

## 1. Purpose

건강기능식품 온라인 허위·과대광고 탐지 MVP의 신고처, 공식 근거, 포상금·보상금 관련 주의사항, 증거요건을 정리한다.
UI와 ReportService가 같은 자료를 불러 쓸 수 있도록 모듈 단위 설정 데이터(`agency_config.json`) 형태로 표준화한다.

## 2. Research Principles

- **공식 자료만 사용**: 정부·공공기관·법령정보센터 공식 URL만 근거로 채택한다.
- **포상금 확정 표현 금지**: 금액, 보장, 자동 수령 등의 단정 표현을 사용하지 않는다.
- **자동 신고 금지**: 외부 신고기관에 대한 자동 제출·자동 로그인 기능을 만들지 않는다.
- **사람 검토 필수**: 외부 신고 전 사람이 법령과 기관 안내 최신본을 직접 확인해야 한다.
- **개념 구분**: "보상금 / 포상금 / 신고포상금"은 적용 근거가 다를 수 있으므로 구분해서 표기한다.
- **블로그·뉴스·법무법인 홍보글·커뮤니티 글은 근거로 사용하지 않는다.**

## 5. Reward and Bounty Caution

- 건강기능식품 **신고포상금**은 관련 고시·규정에 따른 **지급대상, 지급금액, 한도, 제외 사유**가 중요하다.
- **공익신고 보상금·포상금**과 개별 **신고포상금**은 적용 근거·요건이 다를 수 있다.
- 본 프로그램은 **포상금 수령을 보장하지 않는다.**
- UI에서는 "예상 포상금"이라는 표현 대신 **"포상금 가능성 확인 필요"**로 표시한다.
- 동일 위반행위에 대한 **중복 신고는 포상금 지급에서 제외**될 수 있다.
- 구체 금액·한도·제외 사유는 공식 규정과 소관 기관 공지를 직접 확인한다.
- 다음 문구는 사용 금지: "건당 ○○원 확정", "무조건 포상금 지급", "자동 신고로 수익 가능", "포상금 보장", "신고하면 무조건 지급".

## 6. Evidence Standard

### 최소 증거 (Minimum)

| 항목 | 비고 |
|---|---|
| 원본 URL | 공개 페이지에 한정 |
| 수집일시 | 자동 기록 |
| 위반 의심 문구 | 발췌·인용 |
| 화면 캡처 | 페이지 변경 대비 |
| 상품명 또는 광고 제목 | 식별용 |

### 권장 증거 (Recommended)

| 항목 | 비고 |
|---|---|
| PDF 저장본 | 원형 보존 |
| 텍스트 추출본 | 검색·인용 용이 |
| 판매자 표시 정보 | 페이지에 공개된 범위 내 |
| 상품 이미지 | 광고 표현 보조 |
| 반복 광고 정황 | 동일 표현 반복 확인 |
| 관련 법령 후보 | 사람 검토용 메모 |
| AI 분석 요약 | 참고용 (확정 아님) |

### 수집 금지 (Avoid)

- 구매자 개인정보
- 주문내역
- 로그인 후 접근 가능한 비공개 정보
- 민감정보
- 불필요한 개인 식별정보

## 7. Report Readiness Checklist

`agency_config.json`의 `reportReadinessChecklist`와 동일한 항목.

- [ ] 공개 URL인가?
- [ ] 로그인 없이 접근 가능한 자료인가?
- [ ] 원본 URL을 저장했는가?
- [ ] 수집일시가 기록되었는가?
- [ ] 위반 의심 문구가 명확한가?
- [ ] 캡처 또는 PDF가 있는가?
- [ ] 신고처 후보를 확인했는가?
- [ ] 포상금 보장 표현을 제거했는가?
- [ ] 법령·기관 안내 최신본을 사람이 재확인했는가?
- [ ] 사람이 최종 검토했는가?

## 8. Human Review Requirement

- 외부 신고 전 사람이 공식 기관 안내와 법령을 **직접 재확인**해야 한다.
- Case 상태가 `Submitted`가 되는 시점은 **사용자가 실제 신고기관에 제출한 뒤 수동으로 변경**할 때다.
- 본 프로그램은 어떠한 경우에도 외부 기관으로 신고를 **자동 송신하지 않는다.**
- 프로그램은 신고처 후보와 증거 정리를 제공할 뿐이며, **위법 여부를 확정 판단하지 않는다.**

## 9. Future Module Notes

후속 모듈은 같은 패턴으로 **모듈별 `agency_config.json`을 별도 분리**한다.
모듈 간 기관·법령·증거요건·포상금 기준은 다를 수 있으므로 동일 파일에 통합하지 않는다.

- `counterfeit_goods` (위조상품 온라인 판매) — 특허청 (`https://www.kipo.go.kr`)
- `origin_labeling` (원산지 표시 위반) — 농림축산식품부 / 국립농산물품질관리원 / 관세청 / 지자체
- `subsidy_fraud` (보조금 부정수급) — 국민권익위원회 / 보조금 관리 소관 기관 / 지자체
- `bid_collusion` (입찰담합 의심) — 공정거래위원회

각 모듈 추가 시:

1. `src/modules/{moduleId}/agency_config.json`을 본 스키마(`docs/agency_config_schema.md`)대로 작성한다.
2. 공식 URL과 법령은 사람이 직접 조사·확인한 자료만 등록한다.
3. 포상금·보상금 표현은 모두 본 문서의 원칙(확정 표현 금지)을 따른다.
4. 변경 후 `npm run build`, `JSON.parse` 검증, 사람 검토를 거친다.
