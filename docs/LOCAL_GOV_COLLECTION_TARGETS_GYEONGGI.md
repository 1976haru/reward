## 1. 문서 목적

- 보조금 AI 에이전트의 **지자체 공개자료 수집 파일럿 대상**을 정의한다.
- 1차 파일럿은 **경기도와 경기도 31개 시군**을 대상으로 한다.
- 본 문서는 **실제 수집기 구현 전 수집대상 선정 문서**이다.
- 실제 수집·다운로드·파싱은 후속 단계에서 수행한다.
- **공개자료 중심 분석 원칙**과 **개인정보 최소수집 원칙**을 따른다 ([`OPERATING_POLICY.md`](./OPERATING_POLICY.md) §5.5, [`privacy_policy.md`](./privacy_policy.md)).
- 본 문서는 법률 자문이나 운영기관의 공식 안내를 대체하지 않는다.

## 2. 파일럿 선정 기준

- 경기도는 보조금·지원사업 공고가 많고, 시군별 자료 비교가 가능하다.
- 경기도와 31개 시군을 함께 보면 **광역-기초 지자체 간 보조사업 흐름**을 비교할 수 있다.
- 고시·공고, 공고·입법예고, 정보공개, 감사결과, 보조금 공모 게시판을 통해 공개자료 접근 가능성이 있다.
- 최근 **2~3년 자료**를 우선 범위로 설정한다.
- 자료 접근 가능성 / 검색 기능 / 첨부파일 제공 여부 / 개인정보 위험도를 기준으로 우선순위를 정한다.
- "자료 확보 완료"가 아니라 **"수집 대상 선정 / 수집 후보 / 재확인 필요"** 로 표현한다.

## 6. 최근 2~3년 수집 범위

- **기준연도는 실제 수집 실행일 기준 최근 2~3년**으로 계산한다.
- 예: 수집 실행일이 2026년이면 2024~2026년 자료를 우선 검토한다.
- 게시글 작성일 / 공고일 / 사업연도 / 정산연도 / 감사연도를 구분한다.
- 자료가 너무 많을 경우 **보조금 / 정산 / 환수 / 감사결과** 키워드를 우선한다.
- **첨부파일이 있는 게시글**을 우선한다.
- 원문 URL / 첨부파일명 / 게시일 / 담당부서 / 금액 / 사업명 / 대상기관을 기록한다.

## 8. 수집 제외 기준

- **로그인 필요 자료**
- **비공개 게시판**
- **내부 행정망 자료**
- **개인정보가 포함된 개인별 수급자 상세자료**
- **주민등록번호, 계좌번호, 휴대폰번호, 이메일, 상세주소가 포함된 자료**
- **저작권·이용약관상 재사용이 제한된 자료**
- **단순 민원, 홍보성 보도자료, 정책 의견 자료**
- **원문 URL 또는 첨부파일 출처가 불명확한 자료**

수집 도중 위 유형이 발견되면 즉시 `sanitizeForStorage` ([`../src/policy/privacyGuard.ts`](../src/policy/privacyGuard.ts)) 를 통과시키고, 마스킹이 어려운 경우 수집 제외한다. 비공개 / 로그인 / 우회 / 약관 위반 수집은 [`OPERATING_POLICY.md`](./OPERATING_POLICY.md) §2 에 의해 금지된다.

## 9. 지자체 수집 스키마 초안

향후 수집기가 사용할 지자체 수집 대상 표현. 실제 코드는 [`../src/types/localGovCollectionTarget.ts`](../src/types/localGovCollectionTarget.ts) 에 정의되며 본 문서와 항상 동기화되어야 한다.

```typescript
export interface LocalGovCollectionTarget {
  id: string;
  regionLevel: "province" | "city" | "county";
  provinceName: "경기도";
  localGovName: string;
  officialSiteUrl?: string;
  noticeBoardUrl?: string;
  disclosureUrl?: string;
  auditResultUrl?: string;
  subsidyBoardUrl?: string;
  priority: "P0" | "P1" | "P2";
  status: "candidate" | "needs_verification" | "verified" | "excluded";
  searchKeywords: string[];
  targetDocumentTypes: Array<
    | "subsidy_notice"
    | "selection_result"
    | "settlement"
    | "inspection"
    | "audit_result"
    | "recovery_return"
    | "budget_settlement"
    | "ordinance"
  >;
```

### 검증 / 운영 원칙

- **본 문서는 수집대상 선정 문서다.** 실제 수집기는 별도 단계에서 구현되며, 게시판 URL · 검색 경로 · 감사결과 위치는 운영기관의 홈페이지 개편에 따라 갱신되어야 한다.
- 수집기는 [`OPERATING_POLICY.md`](./OPERATING_POLICY.md) §2 (자동 신고 금지), §5 (개인정보 최소 수집), §11 (표현 통제), §12 (사실관계 점검) 정책을 모두 준수해야 한다.
- 수집된 자료를 사실관계 점검 단계로 넘길 때는 [`PRE_SUBMISSION_FACT_CHECKLIST.md`](./PRE_SUBMISSION_FACT_CHECKLIST.md) §3 의 11개 확인 항목 (공개자료 / 원문 URL / 금액 / 기간 / 수급기관 / 사업명 / 의심근거 등) 의 원천 데이터를 채울 수 있어야 한다.
- 본 파일럿의 자료는 **외부 신고기관에 자동 제출되지 않으며**, 사람 검토(`human_review_required`) 단계로만 넘긴다.
- 정적 검증: `npm run test:local-gov-targets` 가 본 문서에 §1~§9 필수 섹션이 모두 존재하는지, [`../src/types/localGovCollectionTarget.ts`](../src/types/localGovCollectionTarget.ts) 에 32개 지자체(광역 1 + 기초 31) 가 정의되어 있는지, 각 대상의 필수 필드가 채워져 있는지 확인한다.
