# 일일 운영 루틴 가이드 (DAILY_OPERATIONS_ROUTINE)

체크리스트 70 산출물. 공익레이더를 **하루 단위로 반복**할 수 있는 운영 루틴이다. 처음에는 하루 1건만
완주해도 충분하다. 자동 신고는 하지 않으며, 수집보다 **검토 품질**이 중요하다.

> - 처음에는 하루 1건만 완주해도 충분합니다.
> - 수집보다 검토 품질이 중요합니다.
> - 자동신고는 하지 않습니다.

---

## 1. 오늘 할 일 (10단계 일일 작업표)
1. **오늘 후보 10건 수집** — 공개자료 기준으로만 수집합니다.
2. **상위 5건 분석** — 룰/점수/설명형 분석으로 우선순위를 봅니다.
3. **상위 2건 증거 패키지 생성** — 공개 URL·캡처·수집일시를 정리합니다.
4. **1건 신고서 초안 생성** — 신고 전 사실점검 11항목을 통과한 후보만 가능합니다.
5. **사람 검토** — 근거·개인정보·표현을 직접 확인합니다.
6. **공식 신고처 링크 확인** — 단순 외부 링크만 확인합니다.
7. **사용자가 직접 신고 여부 결정** — 자동 신고는 하지 않습니다.
8. **수동 제출 시 접수번호 기록** — 직접 제출 후 접수번호를 남깁니다.
9. **처리결과/피드백 기록** — 처리상태·반려·오탐 등을 기록합니다.
10. **다음 개선 후보 확인** — 피드백 개선 후보를 살펴봅니다.

하루 최소 1건 완주가 가능한 루틴입니다(수집 1 → 분석 → 초안 → 검토 → (직접) 신고 → 결과 기록).

## 2. 화면/체크 방법
- 메인 화면의 **"오늘 할 일 / 일일 작업표"** 카드에서 각 단계를 수동 체크합니다.
- 체크 상태는 `data/operations/routine-{YYYY-MM-DD}.json` 에 저장됩니다(gitignore, 커밋하지 않음).
- API:
  - `GET /api/dashboard/daily-routine` — 오늘 10단계 정의 + 체크 상태.
  - `POST /api/dashboard/daily-routine/step` — `{ stepId, done, note? }` 로 단계 체크.

## 3. 운영 현황판 연계
- `GET /api/dashboard/summary` 의 `operations` 블록에서 오늘 수집/분석/검토/신고서 초안/수동 제출/결과 기록 건수와 모듈별 현황·경고·검토 대기·최근 이력을 확인합니다.
- 운영 현황판은 진행상황 확인용이며, 의심 후보는 법 위반 확정이 아니고 실제 신고는 사용자가 공식 창구에서 직접 제출합니다.

## 4. 주의
- 자동 신고/자동 로그인/공식 양식 자동입력/포상금 자동신청은 하지 않습니다.
- 결과·포상 기록은 내부 추적용이며 포상금 지급을 보장하지 않습니다.
- 개인정보·API 키 원문은 기록/로그/화면에 남기지 않습니다(저장 전 마스킹).
