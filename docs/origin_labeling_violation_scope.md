## 2. 목적

- 공개 온라인 판매글에서 **원산지 표시 불일치·누락 의심 신호를 "검토 후보"로 탐지**한다.
- **원산지 표시 위반 여부를 확정하지 않는다.** 위반 판단은 관계기관(국립농산물품질관리원 등)과 사람 검토에 따른다.
- 키워드 매칭은 사람 검토가 필요한 의심 후보를 만들기 위한 보조 자료다.
- 자동 신고를 하지 않으며, 실제 신고는 사람이 공식 창구에서 직접 한다. 포상금 수령은 보장되지 않는다.
- **특정 판매자를 위반 업체로 단정하지 않는다.**

## 3. 포함 범위

- 농수산물·축산물·가공식품 등 온라인 판매글의 **공개 URL** 본문(상품명/옵션/상세페이지/원산지 표시) 검토.
- 다음 유형의 의심 신호 탐지:
  - 국내산/수입산 표시 불일치 의심
  - 원산지 미표시 의심
  - 혼합 원료 원산지 표시 누락 의심
  - 상세페이지와 상품명/옵션/이미지 표시 불일치 의심
  - "국내산" 강조 후 실제 원료는 수입산일 가능성
  - "국산처럼 보이는 표현"과 원산지 정보 부족 조합
  - 산지직송/국내 농가/우리 농산물 표현과 원산지 정보 부족 조합
  - 원산지 별도 표기 없음 / 원산지 문의 유도
  - "수입산 원료 사용 가능" 등 원산지 혼합·모호 표시

## 4. 제외 범위

- 로그인 필요·회원 전용·비공개 SNS·결제 후 접근·CAPTCHA 우회가 필요한 페이지.
- 식품 허위·과대광고(효능·기능성)·화장품·의료기기·위조상품 등 다른 분야(각 모듈에서 다룸).
- 대량 크롤링, 검색엔진 HTML 스크래핑.
- 신고서 자동 제출, 자동 로그인, 공식 양식 자동입력 (전 모듈 공통 금지).
- 원산지 위반 최종 판정(관계기관 영역).

## 5. 식품/화장품/의료기기/위조상품 모듈과의 차이

| 구분 | 식품·화장품·의료기기 | 위조상품 | 원산지(본 모듈) |
|---|---|---|---|
| 핵심 관점 | 허위·과대광고(효능·기능성 오인) | 상표권 침해 의심 | 원산지 표시 불일치·누락 의심 |
| 판단 주체 | 표시·광고 기준(식약처 등) | 권리자·특허청 | 국립농산물품질관리원 등 |
| 대표 신호 | 질병 치료·의약품 오인 | 정품급/미러급/로고 모방 | 국내산/수입산 불일치, 원산지 미표시, 혼합 원료 누락 |
| 확정 여부 | 위반 확정 아님 | 위조 확정 아님 | 위반 확정 아님(검토 후보) |

## 6. 원산지 표시 위반 의심 유형

- **국내산/수입산 표시 불일치:** 표기와 실제 원산지가 다를 가능성 — 검토 후보.
- **원산지 미표시:** 원산지 표시 자체가 없음 — 검토 후보.
- **혼합 원료 원산지 누락:** 혼합 원료의 각 원산지·비율 미표시 — 검토 후보.
- **상세-옵션 불일치:** 상품명/옵션은 국내산, 상세는 수입산 등 — 검토 후보.
- **국산 강조 + 정보 부족:** 국내산을 강조하나 원산지 근거·정보가 부족 — 검토 후보.
- **원산지 문의 유도:** 게시글에 표시하지 않고 문의로 유도 — 검토 후보.

## 7. 음식점/온라인 판매/가공식품별 차이 (참고)

- **온라인 판매(본 모듈 주 대상):** 상품명/옵션/상세페이지의 원산지 표시 불일치·누락을 공개 화면에서 검토.
- **가공식품:** 혼합 원료의 원산지·비율 표시 누락 여부가 핵심 — 표시 기준이 더 세분화됨.
- **음식점:** 메뉴판/게시 원산지 표시가 대상이며 현장 확인이 필요해 본 온라인 모듈의 직접 대상이 아니다(관계기관 현장 점검 영역).

## 8. 공식 신고처 후보

> 단순 링크 안내만 제공하며 자동 제출하지 않는다. URL은 공식 사이트에서 정기적으로 확인이 필요하다.

- 국립농산물품질관리원 (원산지 표시 위반 신고)
- 국민신문고
- 관세청(수입 관련) · 관할 지자체

(신고처 메타데이터의 정식 연결은 다음 단계의 agency_config 작업에서 진행한다.)

## 9. 필요한 증거

- 원본 판매글 URL (공개 페이지)
- 상품명/옵션/상세페이지 원산지 표시 캡처
- 상품 이미지, 원산지 표기 부분 캡처
- 수집일시
- 표시 불일치·누락이 드러나는 화면 위치

## 10. 사람 검토 기준

- 탐지된 표현이 실제 판매글 문맥에서 원산지 표시 불일치·누락 신호인지 사람이 확인.
- 정상 원산지 표시(예: "원산지: 국내산"이 명확히 기재)와 구분(과탐지 여부) 검토.
- 원산지 위반 최종 판단은 관계기관 확인이 필요함을 명시.
- 개인정보·민감정보가 불필요하게 포함되지 않았는지 확인.
- 특정 판매자를 위반 업체로 단정하지 않음.
- 검토 없이 다음 단계(신고)로 진행 불가.

## 11. 자동신고 금지 원칙

- 외부 신고기관 자동 제출, 자동 로그인, 공식 양식 자동입력, 포상금 자동신청을 **하지 않는다.**
- 시스템은 "신고서 초안 복사 / 다운로드 / 공식 링크 열기 / 내부 상태 기록"만 가능하다.
- 실제 신고는 사람이 공식 창구에서 직접 제출한다.
