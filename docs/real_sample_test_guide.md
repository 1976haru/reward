# 실전 샘플 10건 테스트 가이드 (체크리스트 31)

이 문서는 건강기능식품 허위·과대광고 1차 MVP가 **실제 운영 가능한 수준인지 전체 흐름을 검증**하기 위한
"실전 샘플 10건 테스트" 절차를 설명합니다.

> ## 가장 먼저 알아둘 점
>
> - 이 테스트의 목적은 **신고 가능성 확정이 아니라 "시스템 흐름 검증"**입니다.
> - 결과는 **법 위반 확정이 아닙니다.** "의심 후보 / 검토 필요 / 사람 확인 필요"로만 해석합니다.
> - 자동 신고·자동 로그인·자동 제출은 수행하지 않습니다. 실제 신고는 사람이 공식 창구에서 직접 합니다.
> - 포상금 수령은 보장되지 않습니다.
> - **실제 URL 목록과 테스트 리포트는 GitHub에 커밋하지 않습니다.** (`data/manual-tests/`는 gitignored)

---

## 1. 대상 URL 준비 규칙

- 건강기능식품/건강 관련 **공개 광고성 페이지**만 사용합니다.
- 다음은 **제외**합니다: 로그인 필요 페이지, 회원 전용, 비공개 SNS, 결제 후 접근, CAPTCHA 우회가 필요한 페이지.
- 대량 크롤링·검색엔진 HTML 스크래핑은 하지 않습니다. **사람이 1건씩 수동 입력**합니다.
- URL에 개인정보·세션 토큰 같은 **민감한 쿼리 파라미터가 있으면 제거**한 뒤 사용합니다.
- 실제 업체명/개인정보는 리포트에 과하게 저장하지 않습니다.

### 실제 URL로 테스트하려면 (선택)

`data/manual-tests/sample-urls.json` 파일을 만들고 아래 형식으로 공개 URL을 넣습니다. (이 파일은 커밋되지 않습니다.)

```json
{
  "urls": [
    "https://공개-광고-페이지-1",
    "https://공개-광고-페이지-2"
  ]
}
```

파일이 없으면 테스트 러너는 **로컬 합성 샘플 페이지(synthetic)** 를 자동 생성해 사용합니다.
합성 샘플은 실제 업체/개인정보가 없는 가상 문구로만 구성되며, 외부 네트워크를 호출하지 않습니다.

---

## 2. 실행 방법

```bash
# 기본(합성 샘플 10건, 외부 호출 없음). MOCK_AI=true 유지 권장.
npm run test:real-sample
```

러너는 각 URL에 대해 다음 13단계 흐름을 수행합니다.

1. 수동 URL 입력
2. 본문 수집/추출
3. 광고문구/후기/성분/섭취방법/주의사항/판매자 정보 구분
4. 룰 탐지
5. AI 분석 모드 표시 (mock / fallback / real)
6. 위험점수·우선순위 점수 표시
7. 증거 패키지 생성
8. 신고서 초안 생성
9. 사람 검토 대기열(Review Queue) 등록
10. 근거 검증 (citation validation)
11. 개인정보 스캔
12. 공식 신고처 링크 확인
13. 결과 기록은 **실제 제출 없이 테스트 상태로만** 확인 (외부 제출/접수번호 생성 금지)

---

## 3. 결과 리포트

- 저장 위치: `data/manual-tests/` (gitignored)
- 형식: Markdown + JSON 동시 생성
- 포함 항목: testRunId, testedAt, totalUrls, successCount, failureCount, url별 caseId,
  추출/탐지/위험점수/증거/신고서초안/Review Queue/근거검증/개인정보스캔 결과, 오류 목록, 개선 필요 항목, 최종 판정.

### 판정 기준

| 판정 | 조건 |
|---|---|
| `PASS` | 10건 중 8건 이상 Case 생성 + 8건 이상 신고서 초안 생성, 반복 실패 없음, 자동신고 정책 유지 |
| `PASS_WITH_WARNINGS` | 기본 흐름은 통과하나 일부 단계에서 경고/보완 필요 |
| `NEEDS_FIX` | 증거 패키지/근거검증/개인정보스캔 중 하나라도 반복 실패 |
| `BLOCKED` | 자동신고 금지 정책이 깨지거나 서버가 흐름 중단 |

---

## 4. 브라우저 확인

1. `npm run dev` 실행 → http://localhost:3001 접속
2. 건강기능식품 분석 흐름으로 이동, 공개 URL 1~2건을 직접 입력해 확인
3. 본문 추출 / 탐지 카드 / 위험점수 설명 / AI 분석 모드 / 증거 패키지 / 신고서 초안 / 사람 검토 / 근거 검증 / 개인정보 스캔 / 공식 신고처 링크가 보이는지 확인
4. "자동신고 없음 / 사람 검토 필수 / 실제 신고는 사용자가 직접 / 포상금 보장 아님" 문구 유지 확인
5. 오류 발생 시 빨간 중단이 아니라 **안전 안내**로 표시되는지 확인

## 5. 안전 수칙 요약

- ✅ 시스템 흐름 검증용입니다. 신고 가능성/법 위반을 확정하지 않습니다.
- ✅ 공개 페이지만, 사람이 1건씩 수동 입력합니다.
- 🚫 로그인 필요 사이트 분석·대량 크롤링·검색 HTML 스크래핑·CAPTCHA 우회 금지.
- 🚫 실제 외부 신고기관 제출 금지, 접수번호 위조 금지.
- 🚫 실제 URL 목록·테스트 리포트·개인정보·API 키를 GitHub에 커밋하지 않습니다.
