# 의료기기 신고서 초안·신고처 가이드 (체크리스트 42)

이 문서는 의료기기 허위·과대광고 모듈(`medical_device_false_ad`)의 **신고서 초안 템플릿과 신고처 안내** 사용법을 초보자 기준으로 설명합니다.

> 신고서 초안은 **실제 신고 제출이 아니라 사람이 검토·수정할 보조 자료**입니다.
> 본 결과는 법 위반 확정이 아니며, 포상금 지급을 보장하지 않습니다. 실제 신고는 사용자가 공식 창구에서 직접 제출합니다.

## 1. 구성 파일

| 파일 | 역할 |
|---|---|
| `src/modules/medical-device-false-ad/report_template.md` | 신고서 초안 참고 템플릿(사람이 보는 양식) |
| `src/modules/medical-device-false-ad/agency_config.json` | 신고처 후보·증거 기준·표현 정책 메타데이터 |
| `src/services/ReportService.ts` (`buildMedicalDeviceMarkdown`) | `moduleId=medical_device_false_ad` 일 때 자동 선택되는 초안 생성기 |

## 2. 초안 생성 방법

의료기기 Case를 만든 뒤 다음 API로 초안을 생성합니다.

```bash
curl -X POST http://localhost:3001/api/cases/CASE_ID/report/draft
```

- 응답의 `report.markdown` 이 의료기기 전용 템플릿으로 생성됩니다(제목: "의료기기 온라인 허위·과대광고 신고 후보 검토 요청서 초안").
- 산출물은 `data/reports/{caseId}/` 에 저장되며 **GitHub에 커밋되지 않습니다.**

## 3. 초안에 포함되는 항목

제목 / 신고 후보 요약 / 원본 URL / 수집일시 / 상품명·광고 제목 / 의료기기 광고 유형 / 의료기기 허가·인증 확인 필요 여부 / 허가 범위 초과 표현 확인 필요 여부 / 의심 문구 표(위험등급·의심 사유·원문 문맥) / 룰 탐지 결과 / AI 문맥 검토 요약 / 위험점수 / 증거 패키지 목록 / 신고 전 사람 검토 체크리스트 / 공식 신고처 후보 / 중립 신고 문구 예시 / 피해야 할 표현 / "법 위반 확정 아님" / "포상금 지급 보장 아님" / "실제 신고는 사용자가 공식 창구에서 직접 제출".

## 4. 공식 신고처 후보

- 식품의약품안전처 (의료기기 표시·광고 관련 신고)
- 국민신문고
- 관할 지자체 · 보건소 · 관련 행정기관

조회 API: `GET /api/agencies?moduleId=medical_device_false_ad`, `GET /api/policy/approval-gate?moduleId=medical_device_false_ad`.
공식 URL은 변경될 수 있으니 신고 전 공식 사이트에서 확인하세요. 단순 링크 안내만 제공하며 자동 제출하지 않습니다.

## 5. 건강기능식품/일반식품/화장품과의 차이

- 의료기기는 사용·착용하는 기기·기구로, 허가받은 사용 목적·효능 범위가 정해져 있습니다.
- 허가 범위를 넘는 치료·완치·예방 단정, 의료기기가 아닌 제품을 의료기기처럼 표시하는 표현인지 사람이 검토합니다. 최종 판단은 사람이 공식 기준으로 확인합니다.

## 6. 금지 사항

- 자동 신고, 자동 로그인, 공식 양식 자동입력은 만들지 않습니다.
- "불법 확정", "사기 확정", "포상금 보장", "신고 성공 보장" 같은 표현은 사용하지 않습니다.
