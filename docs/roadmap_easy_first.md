# 쉬운 모듈 우선 로드맵과 완성 정의

> 현재 1차 실전 MVP: **건강기능식품 온라인 허위·과대광고 탐지**

공익레이더는 공개 URL과 공개자료로 확인 가능한 광고 문구 분석부터 안정화한다. 이미 만든 기능은 삭제하지 않되, 데이터 준비와 검토 난도가 높은 모듈은 뒤 단계로 운영한다.

## 개발 순서

| 순서 | 모듈 | 단계 |
|---:|---|---|
| 1 | 건강기능식품 온라인 허위·과대광고 탐지 | **1차 실전 MVP / 현재 우선 개발** |
| 2 | 일반식품 온라인 허위·과대광고 탐지 | **2차 쉬운 확장 — 스코프·키워드 룰셋 작성 완료** ([scope](./general_food_false_ad_scope.md), `general_food_false_ad`). 신고서 템플릿·agency_config·E2E 는 다음 단계 |
| 3 | 화장품 온라인 허위·과대광고 탐지 | 후속 쉬운 모듈 |
| 4 | 의료기기 온라인 허위·과대광고 탐지 | 후속 모듈 |
| 5 | 위조상품 온라인 판매 의심 탐지 | 확장 모듈 |
| 6 | 원산지 표시 위반 의심 탐지 | 확장 모듈 |
| 7 | 보조금 부정수급 의심 탐지 | **후순위 고급 모듈 / 프로토타입, 실데이터 준비 후 진행** |
| 8 | 입찰담합 의심 패턴 분석 | **후순위 고급 모듈 / 프로토타입, 실데이터 준비 후 진행** |

보조금 부정수급과 입찰담합 관련 기존 코드·문서·데모는 유지한다. 이는 현재 실전 MVP가 아니라 공개자료 구조와 분석 절차를 검증하는 후순위 프로토타입이다.

## 모든 모듈의 완성 정의

모듈이 실전 완료로 표시되려면 아래 흐름이 처음부터 끝까지 동작하고, 각 단계가 사람 검토 및 안전 정책을 따라야 한다.

1. 공개 URL 또는 공개자료 입력
2. 자료 수집
3. 본문 추출
4. 의심 문구 탐지
5. 위험도/우선순위 점수화
6. 증거 패키지 생성
7. 신고서 초안 생성
8. 사람 검토
9. 공식 신고처 링크 안내
10. 사용자가 외부 공식 창구에 직접 신고
11. 접수번호/처리결과 수동 기록

**신고서 초안 생성은 신고가 아니다. 실제 신고는 사람이 공식 신고처 링크를 열어 직접 작성·제출한다.** 시스템에는 사용자가 제출한 뒤 확인한 접수번호와 처리결과만 수동 기록한다.

## 자동신고 금지 고정 정책

다음 기능은 어느 모듈에도 추가하지 않는다.

- 외부 신고기관 자동 제출 금지
- 신고기관 자동 로그인 금지
- 공식 신고 양식 자동입력 금지
- 포상금 자동신청 금지
- 사람 검토 없는 신고 상태 전환 금지

시스템이 제공하는 범위는 공개자료 분석, 증거 정리, 신고서 초안, 공식 링크 안내, 사람 검토와 수동 제출 기록까지다. 세부 게이트 규칙은 [`approval_gate.md`](./approval_gate.md)를 따른다.
