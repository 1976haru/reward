# 위조상품 신고서 초안·신고처 가이드 (체크리스트 46)

이 문서는 위조상품 온라인 판매 의심 모듈(`counterfeit_goods`)의 **신고서 초안 템플릿과 신고처 안내** 사용법을 초보자 기준으로 설명합니다.

> 신고서 초안은 **실제 신고 제출이 아니라 사람이 검토·수정할 보조 자료**입니다.
> 본 결과는 **위조 여부를 확정하지 않습니다.** 권리자 감정과 관계기관 판단이 별도로 필요하며, 특정 판매자를 위조범으로 단정하지 않습니다. 포상금 지급을 보장하지 않습니다. 실제 신고는 사용자가 공식 창구에서 직접 제출합니다.

## 1. 구성 파일

| 파일 | 역할 |
|---|---|
| `src/modules/counterfeit-goods/report-template.md` | 신고서 초안 참고 템플릿(사람이 보는 양식) |
| `src/modules/counterfeit-goods/agency_config.json` | 신고처 후보·증거 기준·표현 정책 메타데이터 |
| `src/services/ReportService.ts` (`buildCounterfeitMarkdown`) | `moduleId=counterfeit_goods` 일 때 자동 선택되는 초안 생성기 |

## 2. 초안 생성 방법

위조상품 Case를 만든 뒤 다음 API로 초안을 생성합니다.

```bash
curl -X POST http://localhost:3001/api/cases/CASE_ID/report/draft
```

- 응답의 `report.markdown` 이 위조상품 전용 템플릿으로 생성됩니다(제목: "위조상품 온라인 판매 의심 신고 후보 검토 요청서 초안").
- 산출물은 `data/reports/{caseId}/` 에 저장되며 **GitHub에 커밋되지 않습니다.**

## 3. 초안에 포함되는 항목

제목 / 신고 후보 요약 / 원본 URL / 수집일시 / 판매글 제목·상품명 / 브랜드·상표 관련 표현 / 판매 가격·가격대 / 판매 방식 / 위조상품 의심 표현 유형 / 의심 문구 표(위험등급·의심 사유·원문 문맥) / 룰 탐지 결과 / AI 문맥 검토 요약 / 위험점수 / 증거 패키지 목록 / 신고 전 사람 검토 체크리스트 / 공식 신고처 후보 / 중립 신고 문구 예시 / 피해야 할 표현 / "위조 여부 확정 아님" / "권리자 감정·관계기관 판단 필요" / "포상금 지급 보장 아님" / "실제 신고는 사용자가 공식 창구에서 직접 제출".

## 4. 공식 신고처 후보

- 특허청 (위조상품 신고포상금 안내)
- 지식재산침해 원스톱 신고상담센터
- 국민신문고
- 관할 행정기관 · 수사기관 (단순 후보)

조회 API: `GET /api/agencies?moduleId=counterfeit_goods`, `GET /api/policy/approval-gate?moduleId=counterfeit_goods`.
공식 URL은 변경될 수 있으니 신고 전 공식 사이트에서 확인하세요. 단순 링크 안내만 제공하며 자동 제출하지 않습니다.

## 5. 식품/화장품/의료기기와의 차이

- 위조상품은 상표권 침해 의심 영역으로, 위조/정품 최종 판단은 권리자 감정과 관계기관(특허청 등)이 합니다.
- 본 모듈은 공개 판매글의 의심 신호(정품급/미러급/레플리카, 로고 모방, 비정상 저가, 단속 회피 등)를 검토 후보로만 표시합니다.

## 6. 금지 사항

- 자동 신고, 자동 로그인, 공식 양식 자동입력은 만들지 않습니다.
- 비공개 채팅방 수집·판매자 개인정보 추적을 하지 않습니다.
- "위조 확정", "가짜 확정", "범죄 확정", "사기 확정", "포상금 보장", "신고 성공 보장" 같은 표현은 사용하지 않습니다.
- 특정 판매자를 위조범으로 단정하지 않습니다.
