# 리포트 문구 가이드

> Repository / internal project name: `reward-agent-mvp`
> Product display name: 공익레이더 (Public Interest Radar)
> 문서 종류: Neutral Language Guide for Reports / UI / Drafts
> 관련 문서: [`OPERATING_POLICY.md`](./OPERATING_POLICY.md), [`LEGAL_REVIEW.md`](./LEGAL_REVIEW.md), [`PRD.md`](./PRD.md), [`approval_gate.md`](./approval_gate.md), [`report_draft.md`](./report_draft.md)

---

## 1. 목적

- AI 리포트, 신고서 초안, 대시보드, 증거 패키지 설명에서 **단정·비방 표현을 방지**한다.
- 본 시스템은 **위법 여부를 확정하지 않고**, 사람이 검토할 수 있는 의심 신호를 정리하는 보조 도구임을 모든 산출물 언어로 명확히 한다.
- 본 가이드는 [`LEGAL_REVIEW.md`](./LEGAL_REVIEW.md) §9 의 표준 면책 문구와 [`OPERATING_POLICY.md`](./OPERATING_POLICY.md) §6 (허위신고 방지) 의 운영 원칙을 산출물 단어 수준으로 구체화한 운영 기준이다. **법률 자문을 대체하지 않는다.**

## 2. 기본 원칙

- 위법 여부를 단정하지 않는다.
- 개인·단체를 범죄자처럼 표현하지 않는다.
- AI 분석 결과는 "검토 필요 후보" 로만 표현한다.
- 신고 여부는 사람이 최종 판단한다.
- 보상금·포상금 가능성도 확정 표현을 사용하지 않는다.
- 추정과 사실을 구분한다 — 사실은 "확인됨", 추정은 "가능성", "의심", "추정".

## 3. 금지 표현표 (Forbidden Phrases)

다음 표는 **사용자에게 노출되는 산출물(리포트/초안/대시보드/응답 메시지)에서 사용을 금지**한다. 본 표 자체는 정책 정의이므로 본 문서·운영정책·테스트·sanitize 룰 정의 코드에서는 예외적으로 등장한다.

| 금지 표현 | 금지 이유 | 대체 표현 |
|---|---|---|
| 부정수급 확정 | 위법 여부 단정 | 부정수급 의심 신호 |
| 부정수급자 | 개인·단체 낙인 | 의심 사례 관련 대상 |
| 불법 | 법률 판단 단정 | 법령 위반 가능성 검토 필요 |
| 불법 확정 | 법률 판단 단정 | 법령 위반 가능성 검토 필요 |
| 범죄 | 수사·재판 전 단정 | 위법 가능성 검토 필요 |
| 범죄 확정 | 수사·재판 전 단정 | 위법 가능성 검토 필요 |
| 범죄자 | 개인·단체 낙인 | 관련 사업자(검토 필요) |
| 사기 | 고의성 단정 | 허위 신청 가능성 검토 필요 |
| 사기 확정 | 고의성 단정 | 허위 신청 가능성 검토 필요 |
| 사기꾼 | 개인·단체 낙인 | 관련 사업자(검토 필요) |
| 허위 수급자 | 낙인 표현 | 허위 수급 의심 대상 |
| 위법 행위자 | 위법 단정 + 낙인 | 위법 가능성 검토 대상 |
| 반드시 신고 | 사용자 판단 침해 | 신고 검토 필요 |
| 무조건 신고 | 과잉 신고 유도 | 사람 검토 후 판단 |
| 처벌 대상 확정 | 처분 결과 단정 | 처분 가능성 검토 필요 |
| 환수 대상 확정 | 기관 판단 전 단정 | 환수 가능성 검토 필요 |
| 보상금 지급 확정 | 결과 보장 | 보상금 가능성 검토 |
| 유죄 | 사법 판단 단정 | 위법 가능성 검토 필요 |
| 고의 범행 | 고의성·범죄성 단정 | 고의 가능성 검토 필요 |

## 4. 권장 표현표 (Recommended Phrases)

| 상황 | 권장 표현 |
|---|---|
| 반복 수급 패턴 발견 | 반복 수급 패턴이 확인되어 추가 검토가 필요합니다. |
| 증빙자료 부족 | 현재 자료만으로는 판단이 어려우며 추가 증빙 확인이 필요합니다. |
| 동일 주소·유사 단체명 발견 | 동일 주소 또는 유사 명칭 기반의 중복 가능성이 있어 검토가 필요합니다. |
| 목적 외 사용 의심 | 보조금 목적 외 사용 가능성이 있어 지출 내역 확인이 필요합니다. |
| 신고서 초안 생성 | 본 문서는 신고서 초안이며, 실제 신고 여부는 사람이 최종 판단해야 합니다. |
| 보상금 가능성 | 보상금·포상금 가능성은 관계기관 판단에 따라 달라질 수 있습니다. |
| AI 점수 표시 | "위험 점수" 또는 "검토 우선순위 점수" (위법 점수 아님) |
| 우선순위 등급 | "최우선 검토 / 우선 검토 / 검토 필요 / 낮음" (확정 표현 사용 안 함) |
| 결론 문장 | "사람 검토 필요" / "관계기관 확인 필요" |
| 단정 회피 일반형 | "의심 신호" / "검토 필요" / "추정" / "가능성" / "후보" / "위험 신호" / "정황" / "이상 패턴" / "자료상 불일치" |

## 5. AI 리포트 작성 규칙

- 제목에는 "확정", "범죄", "불법" 을 쓰지 않는다.
- 위험도는 "위험 점수" 또는 "검토 우선순위" 로 표현한다.
- 결론은 "신고 필요" 가 아니라 "사람 검토 필요" 로 작성한다.
- 근거는 반드시 자료 기반(원본 URL / 수집일시 / 추출 텍스트 / 해시 manifest) 으로 작성한다.
- 추정과 사실을 구분한다 — "확인됨" vs "가능성/의심/추정".
- 개인정보·민감정보(연락처·이메일·주민번호 등) 는 마스킹한다 (`MaskingService`).
- 신고처 추천은 "공식 신고 창구 후보" 로만 표시하고, "이곳에 신고하면 포상금 지급됨" 같은 단정 금지.

## 6. 신고서 초안 문구 규칙

- "신고합니다" 가 아니라 **"신고 검토 초안"** 또는 **"제보 검토 초안"** 으로 표시한다.
- 실제 제출 전에는 접수번호를 생성하지 않는다. 접수번호(`externalReceiptNo`)는 사람이 외부 공식 창구에서 직접 제출한 뒤에만 입력 가능하다 ([`approval_gate.md`](./approval_gate.md) §11).
- 초안 본문 또는 머리말에 다음 문구를 포함한다.
  > "본 문서는 자동 제출되지 않았으며, 사람이 검토 후 수동 제출해야 합니다."
- 자동 sanitize 규칙은 [`report_draft.md`](./report_draft.md) 및 `src/services/ReportService.ts` 의 치환 테이블이 강제한다 (예: `범죄자 / 사기꾼` → `관련 사업자(검토 필요)`).

## 7. 대시보드 문구 규칙

- "부정수급자 목록" 금지 → "의심 사례 후보 목록" 권장
- "신고 완료" 는 접수번호(`externalReceiptNo`) 가 있는 수동 제출 이후에만 표시. 그 전에는 "신고서 초안 생성" / "사람 검토 필요" / "승인 대기" 로 표시.
- "AI 판정" 금지 → "AI 분석 결과" 또는 "AI 검토 보조 결과" 사용.
- 카드/뱃지 문구도 동일 원칙: "위법 확정" / "포상금 지급 예상" 단정 금지.
- 우선순위 라벨은 ScoringAgent 등급(최우선 검토 / 우선 검토 / 검토 필요 / 낮음)을 사용하고 위법 확정 표현으로 치환하지 않는다.

## 8. 표준 면책 문구 (Standard Disclaimer)

모든 사용자 노출 리포트·초안·증거 패키지 설명·대시보드 카드는 다음 문구 또는 의미상 동일한 변형을 포함한다.

> "본 리포트는 공개자료 및 사용자가 입력한 자료를 바탕으로 생성된 검토 보조 자료입니다. 위법 여부를 확정하지 않으며, 실제 신고 여부와 보상금·포상금 지급 여부는 관계기관의 조사 및 법령상 요건에 따라 달라질 수 있습니다."

추가 표준 문구는 [`LEGAL_REVIEW.md`](./LEGAL_REVIEW.md) §9 (제품 성격 / 사람 검토 / 비보장 / 공직자 / 법률 자문 비대체) 참고.

## 9. 정적 검사

`scripts/check-language-policy.js` 가 README / docs / src / public / tests / scripts 를 스캔해 §3 의 금지 표현을 검출한다. 다음 조건 중 하나면 통과(false positive 방지):

- 같은 ±100 char 윈도우에 부정 마커(아닙니다 / 단정하지 / 표현 없이 / 금지 / 사용하지 / sanitize / replace / 마스킹 등)가 함께 등장 — 즉 의미상 "이 단어를 쓰지 않는다" 는 disclaimer.
- 본 문서, [`OPERATING_POLICY.md`](./OPERATING_POLICY.md), [`LEGAL_REVIEW.md`](./LEGAL_REVIEW.md), [`approval_gate.md`](./approval_gate.md), [`report_draft.md`](./report_draft.md), 모듈 분석 프롬프트/템플릿, sanitize 정의 코드, smoke test, 본 정책 검사 스크립트 자체는 화이트리스트.

실행:

```bash
npm run check:language
npm run check:policy   # check:policy 가 check:language 를 함께 실행
npm run test:language
```

위반이 발견되면 비-0 종료 코드로 실패한다.
