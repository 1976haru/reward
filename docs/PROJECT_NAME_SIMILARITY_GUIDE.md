# 사업명 유사도 가이드 (체크리스트 15)

## 1. 문서 목적

- 보조금 자료, 지자체 공고, 업로드 파일, 공공데이터 API에서 사업명 표기 차이와 유사 사업명을 찾기 위한 기준을 정의한다.
- 본 모듈은 반복 신청 또는 유사 사업을 **확정**하는 도구가 아니라 **"유사 사업명 후보"**와 **"반복 신청 검토 후보"**를 만드는 보조 도구이다.
- 공개자료 중심 분석 원칙과 중립 표현 원칙을 따른다.

관련 코드:

- 표준 타입: [`src/types/projectNameSimilarity.ts`](../src/types/projectNameSimilarity.ts)

## 2. 정규화 대상

- 보조사업명
- 지원사업명
- 공모사업명
- 세부사업명
- 내역사업명
- 계약명과의 비교용 사업명
- 정산자료의 사업명
- 감사자료의 사업명

## 3. 사업명 정규화 규칙

| 구분 | 원문 예시 | 정규화 기준 |
|---|---|---|
| 연도 | 2024년 청년 문화활동 지원사업 | 연도 토큰 분리 또는 낮은 가중치 |
| 차수 | 1차, 2차, 제3차 | 차수 토큰 분리 또는 낮은 가중치 |
| 괄호 | 청년 문화활동 지원사업(수원시) | 괄호 메모 제거 또는 보조 토큰 |
| 공모 표현 | 공모, 모집, 신청 안내 | 일반 표현으로 낮은 가중치 |
| 사업 표현 | 사업, 지원사업, 보조사업, 프로그램 | 일반 표현으로 낮은 가중치 |
| 특수문자 | 청년-문화_활동 | 청년 문화 활동 |
| 띄어쓰기 | 청년문화활동, 청년 문화 활동 | compactName으로 비교 |
| 대소문자 | Youth Care, youth-care | 소문자화 |
| 지자체명 | 경기도 청년 문화활동 지원 | 지역 보조 토큰으로 분리 |
| 금액 표현 | 최대 500만원 지원 | 금액 토큰 분리 또는 낮은 가중치 |

## 4. 일반 토큰과 중요 토큰

- 일반 토큰 예: 사업, 지원, 보조, 공모, 모집, 신청, 안내, 계획, 추진, 운영, 프로그램, 참여, 대상, 선정, 결과
- 중요 토큰 예: 청년, 아동, 노인, 장애인, 문화, 예술, 창업, 농업, 스마트팜, 돌봄, 교육, 주거, 환경, 마을, 공동체
- 일반 토큰만 남은 사업명은 ambiguous 처리한다.
- 중요 토큰이 많이 겹치면 유사도 가중치를 높인다.
- 사전에 없는 고유 토큰도 자동으로 중요 토큰으로 본다.

## 5. 유사도 기준

| 판정 | 조건 | 처리 |
|---|---|---|
| strong_similar | 유사도 0.90 이상 | 유사 사업명 후보, 사람 검토 |
| similar_candidate | 유사도 0.85 이상 | 반복 신청 검토 후보 |
| possible_candidate | 유사도 0.70 이상 | 보조 검토 후보(추가 확인 필요) |
| no_match | 유사도 0.70 미만 | 후보 제외 |
| ambiguous | 일반 토큰만 있거나 너무 짧음 | 사람 검토 필요 |

## 6. 유사도 계산 기준

- compactName 완전 일치
- 중요 토큰 Jaccard/Dice 유사도
- character n-gram(bigram) 유사도
- edit distance 기반 유사도
- 연도·차수·공모 표현은 낮은 가중치
- 지역명은 보조 신호로만 사용
- **형태소 분석기를 사용하지 않고 문자열 기반으로 계산한다.**
- 0.85 이상 후보는 자동 확정이 아니라 검토 후보이다(추가 확인 필요).

## 7. 반복 신청 탐지 활용 기준

- 같은 기관명 후보 + 유사 사업명 후보 + 같은 연도 또는 인접 연도면 검토 우선순위를 높일 수 있다.
- 같은 주소 후보 + 유사 사업명 후보이면 검토 우선순위를 높일 수 있다.
- 사업명 유사도만으로 반복 신청 또는 부정수급을 단정하지 않는다.
- 결과는 **"반복 신청 검토 후보"**로만 표현한다.

## 8. 정확도 검증 기준

- 테스트 데이터는 가짜 사업명으로 구성한다.
- 유사 사업명 변형 20쌍 이상을 만든다.
- 다른 사업명 쌍 10쌍 이상을 만든다.
- 유사 사업명 변형의 80% 이상이 유사도 0.85 이상 또는 similar_candidate 이상이어야 한다.
- 다른 사업명 쌍의 80% 이상은 no_match 또는 possible_candidate 이하로 분류되어야 한다.
- 0.85 이상 후보 목록 생성 테스트가 있어야 한다.

## 9. 후속 작업

- 실제 경기도/지자체 사업명 샘플로 품질 검증
- 형태소 분석기 도입 여부 검토
- 사업 분야별 중요 토큰 사전 보강
- 기관명 정규화 결과와 결합
- 주소 정규화 결과와 결합한 반복 신청 리스크 신호
- 업로드 parser 결과에 projectNameCompactKey 연결
- 사람 검토 UI에서 유사 사업명 후보 표시

---

본 가이드는 사업명 유사도 계산을 위한 보조 기준이며, 반복 신청 또는 유사 사업을 확정하지 않는다. 자동 확정 병합을 수행하지 않으며, 모든 후보는 사람 검토 대상이다. 사업명 유사도만으로 부정수급을 단정하지 않고 보상금 지급을 보장하지 않는다.

## 초보자 안내 — 왜 확정이 아닌가

- **왜 사업명 유사도가 필요한가:** "2024년 1차 청년창업 지원사업"과 "청년 창업 지원사업(2차)"처럼 연도·차수·일반토큰만 다른 사업명을 묶어 "유사 사업명 후보 / 반복 신청 검토 후보"를 찾기 위함입니다.
- **왜 확정 판단이 아닌가:** 유사도 0.85 이상이어도 정상적으로 매년 운영되는 사업일 수 있습니다. 유사도만으로 반복 신청·부정수급을 단정하지 않으며 모든 결과는 `reviewRequired`(사람 검토)입니다.
- **다음 위험룰 연결:** `projectName → normalizedProjectName / projectNameCompactKey(또는 similarityScore)`로 연결되어 다음 단계 **유사 사업명/반복 신청 룰**의 비교 입력이 됩니다(이번 단계는 전처리까지).
- **실데이터 커밋 금지:** 사업명이 포함된 산출물(`data/upload-parser`, `data/collector`, `data/baseline`)은 GitHub에 커밋하지 않습니다.
