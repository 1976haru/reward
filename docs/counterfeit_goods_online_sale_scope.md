# 위조상품 온라인 판매 의심 모듈 스코프 (체크리스트 44)

> 이 문서는 공익레이더의 **쉬운 분야 확장**인 "위조상품 온라인 판매 의심" 모듈의 범위를 정리합니다.
> 이번 단계는 **스코프 문서 + 키워드 룰셋 점검·보강**까지이며, 신고서 템플릿·agency_config·샘플 E2E 테스트는 별도 단계입니다.

## 1. 기본 정보

| 항목 | 내용 |
|---|---|
| 모듈명 | 위조상품 온라인 판매 의심 탐지 (확장) |
| moduleId | `counterfeit_goods` |
| slug | `counterfeit-goods` |
| category | `intellectual_property` |
| 상태(status) | `ready` (룰셋 탐지·리포트 최소 연결 완료) |
| 관계 | **건강기능식품(1차 MVP)·일반식품·화장품·의료기기 모듈을 대체하지 않는 후속 쉬운 확장 모듈** |

## 2. 목적

- 공개 온라인 판매글에서 **위조상품 의심 신호를 "검토 후보"로 탐지**한다.
- **위조 여부를 확정하지 않는다.** 정품/위조 판단은 권리자 감정과 관계기관 판단에 따른다.
- 키워드 매칭은 사람 검토가 필요한 의심 후보를 만들기 위한 보조 자료다.
- 자동 신고를 하지 않으며, 실제 신고는 사람이 공식 창구에서 직접 한다. 포상금 수령은 보장되지 않는다.
- **특정 판매자를 위조범으로 단정하지 않는다.**

## 3. 포함 범위

- 공개 판매게시글의 **공개 URL** 본문(상품 설명/가격/구성품/판매자 공개 정보) 검토.
- 다음 유형의 의심 신호 탐지:
  - 정품급·미러급·레플리카·rep급·SA급·S급·AAA급 등 위조 등급 표현
  - 병행수입 위장 표현(병행수입 정품 보장 등)
  - 로고/상표/브랜드 오인·모방 구현 표현
  - 정품 보장 표현과 지나치게 낮은 가격(비정상 저가)의 조합
  - 구매대행/해외직구/재고정리 표현을 통한 오인 가능성
  - 해외공장/공장직송/공장판 표현
  - 구성품/풀박스/택/시리얼/보증서 등 정품 구성품 모방 표현
  - 단속·세관 회피성 표현, 비공개 채널 거래 유도
  - 브랜드명 + 가품 암시 표현 조합

## 4. 제외 범위

- 로그인 필요·회원 전용·비공개 SNS·결제 후 접근·CAPTCHA 우회가 필요한 페이지.
- 건강기능식품/일반식품/화장품/의료기기 등 표시·광고 분야(각 모듈에서 다룸).
- 비공개 채팅방 내부 수집, 판매자 개인정보 추적.
- 대량 크롤링, 검색엔진 HTML 스크래핑.
- 신고서 자동 제출, 자동 로그인, 공식 양식 자동입력 (전 모듈 공통 금지).
- 정품/위조 최종 감정(권리자·관계기관 영역).

## 5. 식품/화장품/의료기기 모듈과의 차이

| 구분 | 식품·화장품·의료기기 | 위조상품(본 모듈) |
|---|---|---|
| 핵심 관점 | 허위·과대광고(효능·기능성 오인) | 상표권 침해 의심(정품 모방·위조 등급·단속 회피) |
| 판단 주체 | 표시·광고 기준(식약처 등) | 권리자 감정 + 관계기관(특허청 등) |
| 대표 신호 | 질병 치료·의약품 오인 | 레플리카/미러급/정품급, 로고 모방, 비정상 저가 |
| 확정 여부 | 위반 확정 아님(검토 후보) | 위조 확정 아님(검토 후보) |

## 6. 위조상품 온라인 판매에서 주의할 의심 유형

- **정품급 표현:** 정품이 아님을 사실상 인정하는 등급 표현 — 검토 후보.
- **미러급 표현:** 정품과 동일 외관을 암시 — 검토 후보.
- **병행수입 위장:** 병행수입 정품이라며 위조를 감추는 표현 — 가격·구성과 함께 검토.
- **로고/상표 오인:** 자체제작 로고·로고 구현·각인 구현 등 모방 표현 — 검토.
- **정품 보장 + 비정상 저가 조합:** 정품 보장과 지나치게 낮은 가격이 함께 등장 — 검토.
- **구매대행/해외직구/재고정리 오인:** 정식 유통처럼 보이게 하는 표현 — 문맥 검토.
- **브랜드명 + 가품 암시 조합:** 유명 브랜드명과 위조 등급 표현이 함께 등장 — 검토.

## 7. 공식 신고처 후보

> 단순 링크 안내만 제공하며 자동 제출하지 않는다. URL은 공식 사이트에서 정기적으로 확인이 필요하다.

- 특허청 (위조상품 신고포상금제도 / 지식재산침해 신고상담센터)
- 국민신문고
- 관세청 (수입 위조품 관련) · 관할 지자체

(신고처 메타데이터의 정식 연결은 신고서 템플릿/agency_config 단계에서 진행한다.)

## 8. 필요한 증거

- 원본 판매게시글 URL (공개 페이지)
- 상품 설명 원문 / 화면 캡처 / PDF 저장본
- 상품명·브랜드 표시·가격
- 상품 이미지, 로고/상표 표시 캡처
- 판매자 공개 정보(개인정보 제외), 동일 판매자 추정 근거
- 수집일시

## 9. 사람 검토 기준

- 탐지된 표현이 실제 판매글 문맥에서 위조 의심 신호인지 사람이 확인.
- 정상 병행수입·중고·구매대행 판매와 구분(과탐지 여부) 검토.
- 정품/위조 최종 판단은 권리자 감정과 관계기관 확인이 필요함을 명시.
- 개인정보·민감정보가 불필요하게 포함되지 않았는지 확인.
- 특정 판매자를 위조범으로 단정하지 않음.
- 검토 없이 다음 단계(신고)로 진행 불가.

## 10. 자동신고 금지 원칙

- 외부 신고기관 자동 제출, 자동 로그인, 공식 양식 자동입력, 포상금 자동신청을 **하지 않는다.**
- 비공개 채팅방 수집·판매자 개인정보 추적을 하지 않는다.
- 시스템은 "신고서 초안 복사 / 다운로드 / 공식 링크 열기 / 내부 상태 기록"만 가능하다.
- 실제 신고는 사람이 공식 창구에서 직접 제출한다.
