# 원산지 표시 위반 신고서 초안·신고처 가이드 (체크리스트 50)

이 문서는 원산지 표시 위반 의심 모듈(`origin_labeling`)의 **신고서 초안 템플릿과 신고처 안내** 사용법을 초보자 기준으로 설명합니다.

> 신고서 초안은 **실제 신고 제출이 아니라 사람이 검토·수정할 보조 자료**입니다.
> 본 결과는 **원산지 표시 위반 확정이 아닙니다.** 관계기관 판단이 별도로 필요하며, 특정 판매자를 위반 업체로 단정하지 않습니다. 포상금 지급을 보장하지 않습니다. 실제 신고는 사용자가 공식 창구에서 직접 제출합니다.

## 1. 구성 파일

| 파일 | 역할 |
|---|---|
| `src/modules/origin-labeling/report_template.md` | 신고서 초안 참고 템플릿(사람이 보는 양식) |
| `src/modules/origin-labeling/agency_config.json` | 신고처 후보·증거 기준·표현 정책 메타데이터 |
| `src/services/ReportService.ts` (`buildOriginLabelingMarkdown`) | `moduleId=origin_labeling` 일 때 자동 선택되는 초안 생성기 |

## 2. 초안 생성 방법

원산지 Case를 만든 뒤 다음 API로 초안을 생성합니다.

```bash
curl -X POST http://localhost:3001/api/cases/CASE_ID/report/draft
```

- 응답의 `report.markdown` 이 원산지 전용 템플릿으로 생성됩니다(제목: "원산지 표시 위반 의심 신고 후보 검토 요청서 초안").
- 산출물은 `data/reports/{caseId}/` 에 저장되며 **GitHub에 커밋되지 않습니다.**

## 3. 초안에 포함되는 항목

제목 / 신고 후보 요약 / 원본 URL / 수집일시 / 상품명·판매글 제목 / 표시된 원산지 정보 / 원산지 미표시·불일치 의심 항목 / 국내산·수입산·혼합원료 관련 표현 / 상품명·옵션·상세페이지·이미지 표시 불일치 여부 / 의심 문구 표(위험등급·의심 사유·원문 문맥) / 룰 탐지 결과 / AI 문맥 검토 요약 / 위험점수 / 증거 패키지 목록 / 신고 전 사람 검토 체크리스트 / 공식 신고처 후보 / 중립 신고 문구 예시 / 피해야 할 표현 / "원산지 표시 위반 확정 아님" / "관계기관 판단 필요" / "포상금 지급 보장 아님" / "실제 신고는 사용자가 공식 창구에서 직접 제출".

## 4. 공식 신고처 후보

- 국립농산물품질관리원 (원산지 표시 위반 신고)
- 국민신문고
- 관할 지자체 · 관련 행정기관

조회 API: `GET /api/agencies?moduleId=origin_labeling`, `GET /api/policy/approval-gate?moduleId=origin_labeling`.
공식 URL은 변경될 수 있으니 신고 전 공식 사이트에서 확인하세요. 단순 링크 안내만 제공하며 자동 제출하지 않습니다.

## 5. 다른 모듈과의 차이

- 원산지 표시 위반은 표시·광고(효능) 영역이 아니라 **표시 불일치·누락** 영역입니다. 위반 최종 판단은 관계기관(국립농산물품질관리원 등)이 합니다.
- 본 모듈은 공개 판매글의 표시 불일치·누락 의심 신호(국내산/수입산 불일치, 원산지 미표시, 혼합 원료 누락, 국산 강조+정보 부족 등)를 검토 후보로만 표시합니다.

## 6. 5건 샘플 E2E 테스트

```bash
npm run test:origin-labeling-sample
```

합성 5건(외부 호출 없음)으로 수집→추출→원산지 룰 탐지→점수→증거→원산지 신고서 초안→검토대기열→근거검증→개인정보스캔→공식 신고처 링크 흐름을 검증하고, `data/manual-tests/`(gitignored)에 JSON/MD 리포트와 PASS/PASS_WITH_WARNINGS/NEEDS_FIX/BLOCKED 판정을 남깁니다. 실제 공개 URL은 `data/manual-tests/sample-urls-origin-labeling.json`에 넣으면 사용됩니다.

## 7. 금지 사항

- 자동 신고, 자동 로그인, 공식 양식 자동입력은 만들지 않습니다.
- 로그인 필요 사이트 분석·대량 크롤링·검색엔진 HTML 스크래핑을 하지 않습니다.
- "위반 확정", "허위 원산지 확정", "범죄 확정", "사기 확정", "포상금 보장", "신고 성공 보장" 같은 표현은 사용하지 않습니다.
- 특정 판매자를 위반 업체로 단정하지 않습니다.
