신고서 초안

신고서 초안은 Case 단위로 생성·다운로드됩니다. 사용자는 다운로드한 초안을 검토·수정한 뒤 외부 공식 창구에 직접 제출합니다.

신고서 초안 사용 흐름

  1. 분석/증거 화면에서 Case를 만들고 분석 결과·증거 패키지를 확인합니다.
  2. 검토 대기열에서 Case를 선택해 상태를 REPORT_DRAFT로 전환하면 신고서 초안이 생성됩니다.
  3. 신고서 초안은 data/reports/{caseId}/ 에 저장되며, Case 상세에서 Markdown / Plain Text / DOCX 형식으로 다운로드할 수 있습니다.
  4. 사용자가 초안을 검토·수정한 뒤 외부 공식 신고기관(식약처·특허청·공정위·국민권익위 등) 창구에 직접 제출합니다.
  5. 제출 후 결과 기록 (Outcome Tracker)에 사람이 직접 제출 결과를 입력합니다.

⚠ 공익레이더는 외부 신고기관에 자동으로 제출하지 않습니다. 신고서 초안에는 "포상금 수령 보장", "법 위반 확정", "사기" 등 단정성 표현이 자동으로 중립화되어 들어가지 않습니다. 신고서 본문은 사람이 다시 검토해야 합니다.

공식 신고처 빠른 이동

신고서 초안 다운로드 후 사용자가 직접 접속해 제출해야 하는 공식 창구입니다. 공식 기준은 변경될 수 있으므로 사람이 직접 재확인하세요.

식품의약품안전처 — 온라인 불법유통 신고 ↗ 특허청 — 위조상품 신고포상금제도 ↗ 공정거래위원회 — 신고포상금 안내 ↗ 국민권익위원회 — 청렴포털 ↗ 국민신문고 ↗

자동 제출 / 자동 로그인 기능은 제공하지 않습니다. 사용자가 사람이 위 페이지에 접속해 직접 제출합니다.

아직 분석을 실행하지 않았습니다. 위에서 "Sample 입찰 데이터 분석 실행"을 눌러 패턴 분석을 시작하세요.
