모듈형 공익신고 후보 탐지·증거정리 에이전트

공개자료를 수집·분석해 의심 문구와 증거를 정리하고 신고서 초안을 만듭니다. 자동 신고는 수행하지 않으며, 최종 신고 여부는 반드시 사람이 검토한 뒤 직접 외부 신고기관에 제출합니다.

⚠ 자동 신고가 아니라, 공개자료 기반 신고 후보 탐지·증거정리·신고서 초안 생성 도구입니다. 현재 사용 가능 모듈: 건강기능식품 온라인 허위·과대광고 탐지 (1차 MVP). 포상금 수령을 보장하지 않으며, AI 분석은 참고용입니다. 자세한 정책은 scope.md·mvp_scope.md를 참고하세요.

신고 분야 선택

1차 MVP 사용 가능 모듈은 건강기능식품 온라인 허위·과대광고 탐지입니다. 일반 식품·화장품·의료기기·기타 분야는 같은 패턴으로 순차 확장 예정입니다.

모듈을 선택하면 가이드가 표시됩니다.

원스톱 프로세스

URL을 분석하면 아래 7단계가 순서대로 수행됩니다. 마지막 단계인 사람 검토는 도구가 아닌 사용자가 수행해야 합니다.

1단계 · 신고 후보 자동 발굴

분야와 탐색 주제를 선택하면 공개 자료 기반으로 신고 후보 URL을 찾아옵니다. 본문 분석과 사람 검토는 다음 단계에서 진행합니다.

안전 정책
  • 대량 크롤링·로그인 우회·CAPTCHA 우회는 수행하지 않습니다.
  • 현재는 MOCK_DISCOVERY=true 기준으로 .test/.example 예약 도메인 후보를 시연합니다. 실제 검색 API 연결은 다음 단계입니다.
  • 후보 발굴 결과는 신고 대상 확정이 아니며, 본문 분석과 사람 검토가 필요합니다.

2단계 · 후보 URL 목록

각 후보의 1차 점수는 본문을 열기 전 제목·요약·URL만 보고 매긴 우선순위입니다. "분석하기"를 누르면 본문을 수집해 정밀 분석과 Case 생성을 진행합니다.

아직 후보가 없습니다. 위에서 "후보 자동 찾기"를 실행하세요.
보조 · 수동 URL 분석 (직접 URL 입력)

자동 발굴 외에 직접 URL을 분석하고 싶을 때 사용합니다. 결과는 동일한 분석 파이프라인을 거칩니다.



입력 전 확인하세요
  • 공개 URL만 입력하세요. 로그인 필요 페이지, 비공개 자료, 개인정보가 포함된 페이지는 입력하지 마세요.
  • 대상 사이트의 이용약관과 robots.txt를 존중해 주세요.
  • 분석 결과는 신고 후보 참고자료이며, 최종 판단·신고는 사람이 직접 합니다.

분석 결과

아직 분석 결과가 없습니다. 위에서 공개 URL을 입력해 분석을 시작하세요.

증거 패키지

분석이 끝나면 원본 URL, 수집일시, 캡처, PDF, 텍스트, 신고서 초안 정보가 표시됩니다.

Human Review Queue (사람 검토 대기열)

AI가 찾은 Case를 사람이 검토·승인·보류·신고초안·제출(내부 기록)·결과확인·폐기 단계로 관리합니다. 외부 신고기관에 자동 제출하지 않습니다.
